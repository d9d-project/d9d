# Metric Catalogue

## About


The `d9d.metric.impl` package provides ready-to-use metrics. They implement the `Metric` interface, so they synchronize across ranks like any other metric.

## Navigation

*   **[Aggregation Metrics](./aggregation.md)**: `SumMetric`, `WeightedMeanMetric`.
*   **[Classification Metrics](./classification.md)**: `BinaryAUROCMetric` and confusion-matrix metrics (accuracy, precision, recall, F-beta).
*   **[Container Metrics](./container.md)**: `ComposeMetric`.
