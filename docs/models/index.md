# Model Catalogue

## About

The `d9d.models` package contains ready-to-use models. Each model comes with a default horizontal parallelism and with state mappers for Hugging Face checkpoints.

*   **[Decoder with Heads](./decoder.md)**: The decoder backbone composed with one or several task heads.
*   **[Qwen3 MoE](./qwen3_moe.md)**: The Qwen3 Mixture of Experts model.
*   **[Qwen3 Dense](./qwen3_dense.md)**: The dense Qwen3 model.
