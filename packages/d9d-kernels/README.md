# d9d-kernels

![PyPI - Version](https://img.shields.io/pypi/v/d9d-kernels)
![PyPI - License](https://img.shields.io/pypi/l/d9d-kernels)

**d9d-kernels** is a set of GPU kernels for training in PyTorch. It comes from the [d9d](https://github.com/d9d-project/d9d) training framework, but does not depend on it.

> [!WARNING]
> d9d-kernels is in alpha, so public APIs can change between minor releases. It is released together with d9d, under the same version. Read the [changelog](https://github.com/d9d-project/d9d/blob/main/CHANGELOG.md) before you upgrade.

## Install

```bash
pip install d9d-kernels
```
